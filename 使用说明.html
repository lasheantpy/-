文献港 PaperHarbor 0.2.0

面向英文数学与计算数学研究的 Windows 桌面检索与公开资料收集软件。更新日期：2026-10-28。

开始使用

  1. 本机双击桌面的「文献港 PaperHarbor」；便携包请先完整解压，再双击「启动文献港.cmd」。
  2. 输入英文关键词、完整标题或 DOI，勾选自动检索来源，点击「搜索论文」。
  3. 点击结果第一列的方框勾选要保存的论文。标题高亮只表示查看详情。
  4. 检查保存目录，点击「下载所选正文 + 补充材料」。
  5. 完成后可点「打开正文 PDF」或「查看下载结果」。报告会区分正文成功、未取得全文和附件状态。

本机默认资料库为 D:\Codex\PaperHarbor\library；便携包默认保存在解压目录的 library。

JSON 是来源、状态与校验记录，不是论文正文。仅生成 JSON 表示尚未取得可阅读的正文 PDF。

本版更新

  • 自动检索来源扩展为 OpenAlex、arXiv、Crossref、OpenAIRE、HAL 和 Europe PMC。
  • 每次结果上限提高到 500，来源按需分页；「更多结果」扩大当前查询上限，保留可对应条目的勾选与下载状态。
  • 添加九家出版社网站补查入口，自动汇入结果与外部网站检索分区显示。
  • 显示期刊、出版社与 ISSN；可在当前结果中按期刊或出版社文字筛选。
  • 修复同名同年论文误合并、同一 arXiv 文献因 DOI 缺失而重复的问题，保留各来源及 PDF 版本信息。
  • 提供可阅读的 HTML 下载报告、正文打开入口和逐源网络状态。

自动检索与覆盖范围

来源主要用途
Crossref出版社登记的期刊、图书、会议等 DOI 书目；是期刊覆盖的重要补充
OpenAlex跨学科学术索引、引用信息和公开版本线索
arXiv数学及相关学科预印本
OpenAIRE研究成果与机构仓储聚合
HAL法国开放学术仓储，包含数学及相关研究
Europe PMC生命科学与医学，适合生物数学等交叉主题

旧版配置按版本补选来源：v1 补选 OpenAIRE 与 Crossref，v2 仅补选 Crossref；此后保存的选择会保留。HAL、Europe PMC 可按研究方向勾选。

学术索引可能收录 Elsevier、Springer Nature、Wiley、SIAM、AMS 等出版平台的论文，但收录范围、元数据字段和更新速度各不相同。收录一条书目不等于拥有全文权限。

每个来源最多按本次上限取得候选，最终列表合并去重后最多 500 条。达到上限、分页中断和使用缓存都会在逐源状态中显示。来源返回的总量采用各自搜索口径，不能直接相加，也不是去重后的文献总量。当前结果中的期刊/出版社筛选不会向远端发起新查询。

要提高覆盖面，可勾选多个合适来源，再按同义词、完整标题及年份分别检索；超过 500 条时分年份或收窄主题。一次查询不代表穷尽检索。普通关键词通常最便于跨来源搜索，复杂布尔式与字段语法在各来源不保证等价。

缓存有效 24 小时；失败时可能恢复旧缓存，界面会明确标注。网络中断或限流不影响其他来源已取得的结果。点击「查看各来源状态」可查看逐源数量、分页状态及错误原因。

出版社网站补查

界面中的「出版社网站补查」提供以下官方入口：

  • Elsevier / ScienceDirect
  • Springer Nature Link
  • Wiley Online Library
  • SIAM Publications
  • AMS 期刊入口
  • Cambridge Core
  • Oxford Academic
  • Taylor & Francis
  • De Gruyter Brill

这些按钮打开浏览器进行补充检索，网站结果不会自动进入软件列表。大部分入口携带当前关键词；AMS 使用官方期刊门户，请先点击复制关键词，再在站内搜索。年份、排序及其他条件需在网站内设置。网站可能需要浏览器验证或机构访问权限。

正文与补充材料

程序同时尝试公开正文 PDF 与公开补充材料。下载后检查文件格式并解析 PDF 页面，HTML 登录页不会被当作正文。

期刊记录可能只找到预印本或作者接收稿；详情中的 PDF 版本和出处应一并查看。

附件支持 PDF、ZIP、CSV、UTF-8/UTF-16 TXT、XLSX、DOCX 和常见图片。ZIP 只做校验，不解压或执行其中内容。正文最大 64 MB，单个附件最大 32 MB，每篇最多自动检查三个落地页、取得八个附件。

提示含义
正文已下载 / 已存在下载流程完成文件格式验证
未找到公开正文没有取得本程序可用的公开正文候选，不表示论文不存在
正文下载失败存在候选，但请求或格式校验未成功
附件未识别到直链已检查页面未识别到支持的链接，不代表没有附件
附件检查未完成超时、访问受限或仍需手动查看
附件部分完成已保存部分文件，仍有未完成项目

再次下载会复验已有文件并跳过有效文件；损坏文件保留，新文件另存。取消会保留已完成文件；未完成文件下次重试，不支持字节续传。「勾选失败项」可选中需重试的条目。关闭正在下载的窗口，会先取消并保存批次状态。

报告生成时，仅对仍存在且通过 PDF 文件头检查的正文显示打开链接；生成后移动或删除文件不会自动更新报告。程序仅访问公开链接，不绕过登录、付费或访问限制。

引用与本地数据

「导出 CSV / BibTeX / RIS」只导出勾选条目，另附 JSON 来源记录；下载时也会自动导出。

导出区分期刊、预印本、图书和章节。正式引用前仍需核对作者、卷期页码及年份。

  • dist/PaperHarbor：独立 EXE 及运行库，必须保持完整。
  • assets：应用图标。
  • data：个人设置、结果与缓存，不包含在新便携包中。
  • library：下载资料，不包含在新便携包中。
  • README.md / 使用说明.html：使用说明。
  • HANDOFF.md、tests、validation、build：源码项目的维护与验证文件。

本机更新保留 data 与 library。便携包无需 Python 或 Codex。已有桌面快捷方式指向本机项目目录；移动项目后需重新创建。

开发与验证

源码使用 Python 3.12，安装 requirements.txt 后可运行 launch.pyw。

离线测试：python -X utf8 -m unittest discover -s tests -v

构建：python build_package.py --wait

构建到暂存位置：python build_package.py --wait --dist-dir <暂存目录>

独立包检查：PaperHarbor.exe --self-check；加 --offline 可跳过联网。

自检在 validation 下隔离设置，不依赖先前的搜索缓存，不覆盖用户设置。

Windows 打包时保留运行时原有 TLS 证书配置，启用正常 HTTPS 校验。

官方参考：OpenAlex、arXiv、Crossref、OpenAIRE、HAL、Europe PMC。
